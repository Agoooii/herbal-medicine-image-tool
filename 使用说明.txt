===============================================================
  中药饮片图片批量处理工具 —— 使用说明
===============================================================

重要提示
  当前版本基于模拟黑色背景测试（白底图手工转黑底），尚未用真实黑色吸光布
  实拍图验证。首次使用真实黑底图时，建议先跑 5-10 张检查效果，确认合格后
  再批量处理。参考下方拍摄建议。

拍摄建议
  工具对照片背景有要求，背景越纯黑，效果越好。拍摄时注意：
    1. 使用纯黑吸光布作为背景（不要用灰布、桌面、白纸）
    2. 产品不要铺满画面，四周留出一些黑边
    3. 深色包装的产品，拍摄时要平衡好背景纯黑和凸显产品主体两大要求，布光需均匀
    4. 对焦清晰，产品边缘不要模糊，袋装中药饮片要尽可能把袋子四周抻平

  标尺图放入须知
    标尺图必须正着放入（「楚杏堂药业」字样在上方），工具不会自动旋转。

===============================================================
  已知限制（请务必阅读）
===============================================================

  工具在以下情况下抠图质量会下降，每次处理建议抽查 5-10 张：

    1. 深色产品（熟地、制首乌、深色外包装）
       → 产品边缘可能被误删，检查深色产品的白底图边缘是否完整

    2. 透明塑料袋装产品
       → 袋子边缘可能模糊或缺损，检查透明袋产品边缘

    3. 非纯黑背景拍摄的图
       → 不要放进工具跑，出来的图会有黑斑或残缺

===============================================================

===============================================================
  这个工具做什么？
===============================================================

  • 产品图：自动抠图 → 白底 → 1:1比例 → 压缩
  • 压缩图：把已有图片缩放并压缩到指定规格
  • 标尺图：自动抠图 → 白底 → 1:1比例 → 压缩

===============================================================
  第一次使用（只需做一次）
===============================================================

  第1步：安装 Python
    打开浏览器，搜索「python 下载」，进入 python.org
    根据电脑型号选择下载，安装时一定要勾选「Add Python to PATH」

  第2步：安装依赖包
    按键盘 Win+R，输入 cmd，回车
    在黑色窗口里输入下面这行，回车：
    pip install opencv-python pillow numpy -i https://pypi.tuna.tsinghua.edu.cn/simple

    等待下载完成，最后一行出现以下提示说明安装成功：
    Successfully installed numpy-xxx opencv-python-xxx pillow-xxx

    如果提示「下载超时」或「timed out」，换成阿里云镜像重试：
    pip install opencv-python pillow numpy -i https://mirrors.aliyun.com/pypi/simple/

===============================================================
  工具核心文件说明
===============================================================

  • process.py   → 主程序，所有处理逻辑都在里面。不要双击它
  • 开始（绿色播放键）→ 启动器。双击这个运行工具
  • folders.ini  → 配置文件，记录每个文件夹的处理方式和参数
  • requirements.txt → 依赖清单，给新电脑装环境用的
  • start.ico    → 图标文件，删了「开始」会变回白框

  这五个文件不能删、不能改名、不能移走。它们必须留在「中药饮片图片批量处理工具」根目录。

===============================================================
  四个工作文件夹
===============================================================

  • 药师帮_产品图                   → 抠图 → 白底 → 1:1 → 压缩，输出 1200×1200 ≤3MB
  • 药师帮_标尺图                   → 抠图 → 白底 → 1:1 → 压缩，输出 1200×1200 ≤3MB
  • 药师帮_主图压缩（1200x1200）     → 纯压缩，输出 1200×1200 ≤3MB
  • 1药城_压缩（800x800像素）        → 纯压缩，输出 800×800 ≤2MB

  使用方法：放图到对应文件夹 → 双击绿色「开始」按钮→ 去「已完成」取结果
  可以在文件夹里建子文件夹分批次，输出会自动镜像目录结构

===============================================================
  1药城压缩图复用说明
===============================================================

  1药城输出的 800×800 图可以直接给药师帮使用（800×800 ≤2MB 满足药师帮 ≤3MB 要求）。
  但注意：原图如果是大尺寸高清图，缩小到 800×800 后清晰度可能会下降。
  如果对清晰度有要求，请用药师帮_主图压缩（1200x1200）输出。

===============================================================
  把文件夹放到桌面（方便操作）
===============================================================

  整个工具包最好放在 D 盘或 E 盘，不要放在桌面。
  如果想把常用的文件夹和启动按钮放桌面，按以下操作：

    1. 打开「中药饮片图片批量处理工具」文件夹
    2. 右键点击你要用的文件夹（比如「药师帮_产品图」）
    3. 选择「发送到」→「桌面快捷方式」
    4. 同样把绿色的「开始」也发送到桌面

  桌面上会有三个快捷方式：两个工作文件夹 + 一个绿色启动按钮。
  放图到文件夹 → 点「开始」运行 → 去文件夹里「已完成」取结果。全程不用离开桌面。

===============================================================
  日常使用（每次处理图片）
===============================================================

  第1步：放图片
    双击桌面快捷方式（或直接打开对应工作文件夹）
    在里面新建文件夹（比如叫「6月25日批次」）
    把图片拖进去

  第2步：运行
    打开「中药饮片图片批量处理工具」文件夹
    双击绿色「开始」按钮
    等待自动处理完成，弹出「处理完成」提示

  第3步：取结果
    打开对应文件夹 →「已完成」→ 你的批次文件夹
    处理好的图片就在里面

===============================================================
  常见问题
===============================================================

  Q：双击绿色「开始」按钮没反应？
  A：没装 Python 或没勾选「Add to PATH」，重新安装 Python。

  Q：处理出来的图有黑色斑块？
  A：原图背景不是纯黑色。请用纯黑吸光布拍摄，产品四周留黑边。

  Q：1药城的图可以给药师帮用吗？
  A：可以，800×800 ≤2MB 满足药师帮要求，但清晰度可能不如 1200×1200。

  Q：桌面快捷方式删了会影响工具吗？
  A：不会。快捷方式只是入口，删了可以随时重新创建。

  Q：想把工具发给同事用？
  A：把整个「中药饮片图片批量处理工具」文件夹发过去，让对方从「第一次使用」开始操作。

  Q：不小心把整个工作文件夹删了（比如「药师帮_产品图」）？
  A：在「中药饮片图片批量处理工具」文件夹里手动新建一个同名文件夹（名字要一模一样），
     再建一个「已完成」子文件夹即可恢复。

  Q：不小心删了「已完成」文件夹？
  A：不用担心。工具下次运行时会自动重建「已完成」文件夹。
     原图还在的话，双击绿色「开始」按钮重跑一次就恢复了。

  Q：不小心删了绿色图标（start.ico）？
  A：不影响使用。绿色「开始」按钮会变成默认白色图标，双击照样运行。
     想恢复的话，把 start.ico 放回原位即可。

  Q：不小心删了原图？
  A：重新把原图放回对应文件夹，再双击绿色「开始」按钮运行一次。
