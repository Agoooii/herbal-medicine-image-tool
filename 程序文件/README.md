# 中药饮片图片批量处理工具 v8

直接双击 `开始.bat`，处理结果仍在各输入文件夹的 `已完成/`。
原始图片不会被修改。`程序文件/folders.ini` 使用 JSON 格式。维护命令请在“程序文件”目录打开终端执行。

## 当前输出

| 文件夹 | 功能 | 输出 |
|---|---|---|
| 药师帮_产品图 | 本地 AI 抠图、白底、等比居中 | 1200×1200，≤3072 KB |
| 药师帮_标尺图 | 整块标尺板外边界检测、白底、等比居中 | 1200×1200，≤3072 KB |
| 药师帮_主图压缩（1200x1200） | 只缩放压缩 | 1200×1200，≤3072 KB |
| 1药城_压缩（800x800像素） | 只缩放压缩 | 800×800，≤2000 KB |

规格依据用户提供的《中药饮片图片批量处理工具使用说明.docx》：药师帮 1200×1200、≤3MB；1药城 800×800、≤2MB（配置采用更严格的 2000KB）。未额外核实平台实时规则。
抠图模式支持根目录图片与多层子目录同时处理，自动排除 `已完成/`。

## 本次抠图改进

- 产品图默认采用 BiRefNet Lite；模型批量复用，每批不再重复加载。
- 检测到多个分离主体或主体过小时，增加背景上下文重新推理。新增背景仅供模型判断，输出使用原照片内容。
- 封闭包装内部填洞，避免深色药材、标签或反光处被挖空。
- 仅沿轮廓做小范围引导滤波，不用凸包拉直袋子褶皱，不默认腐蚀袋角。
- 根据透明蒙版裁切，保留浅色和细小边角。使用预乘透明度缩放，减少缩放造成的脏边。
- 抠图输出固定像素；体积无法达标时明确报错，不偷偷降低像素或返回超限图片。
- 默认不生成处理报告，“已完成”仅保存成品图片，异常在运行窗口提示。仅维护验证时显式设置 `save_report: true` 才生成 `处理报告.json`：`ok` 表示未触发启发式异常，`review` 表示生成了图片但需要复核，`error` 表示失败。报告不是准确率保证。
- 旧袋装算法保留为 `method: "bag_legacy"`；运行前文件备份在 `程序文件/整理前备份.zip`。

## 环境及模型

Python 3.11 或 3.12。当前机器的模型和依赖已准备好。
换电脑时执行：

```powershell
python -m pip install -r requirements.txt
python 安装抠图模型.py
python process.py
```

首次安装模型需从 rembg 官方发布地址下载约 224 MB。
默认模型位于 `%USERPROFILE%\.u2net\birefnet-general-lite.onnx`，也可通过 `U2NET_HOME` 指定目录。
正常产品图批处理使用本地模型，不上传照片；缺少模型时报错，不自动切回效果较差的旧算法。

模型来源：[BiRefNet](https://github.com/ZhengPeng7/BiRefNet)；推理接口：[rembg](https://github.com/danielgatis/rembg)。本次接入预训练模型及后处理，没有用这五张图训练新模型。

## 常用配置

产品图推荐：

```json
{
  "name": "药师帮_产品图",
  "method": "bag",
  "model": "birefnet-general-lite",
  "erode": 0,
  "feather": 0,
  "pad": 30,
  "size": 1200,
  "max_kb": 3072,
  "fill_holes": true,
  "refine_edges": true
}
```

- `pad`：最终方图留白像素；`erode` 和 `feather` 也按最终输出像素计算。袋装建议保持 0，避免切掉封边。
- `fill_holes`：完整袋装、罐装设为 `true`。带提手孔等真实孔洞的物品设为 `false`。
- `save_mask: true`：额外保存蒙版 PNG，适合检查问题。
- `size: 800, max_kb: 2000`：用于需要抠图后输出 800×800 的任务。可在“抠图模式”增加独立输入文件夹，不要把同一文件夹同时配置到两个模式。
- `method: "board"`：标尺图（整板保留）；`threshold` 仅保留旧阈值算法兼容；`product` 与 `bag` 都走新产品流程。`rembg` 保留旧 ISNet 模型接口，不建议用于这些袋装样图。

`程序文件/验证资料/` 中保存现有 5 张袋装实拍图的旧版结果、候选模型结果和 `新版成品/`。查看 `前后对比.jpg`。


标尺图另用 13 张实拍样图（规范与不规范方向）做了验证；结果保存在 `程序文件/验证资料/标尺优化/`。真实罐装样本仍未提供。
单张单产品是默认场景；多件商品并列不适合“保留主连通主体”的处理。
原图已拍出画面外的袋角无法恢复；透明塑料边缘与背景完全同色时仍可能漏边，透明区域的背景染色也不能靠轮廓处理完全消除。
发生重试、贴边或主体异常会在运行窗口提示，上传前应查看对应图片。

## 标尺图整板模式

`药师帮_标尺图` 默认使用 `method: "board"`，通过板面色差、四边几何和边界对比定位整块板子，将刻度、色卡、板面及其上的饮片全部保留。板内黑色药材与白色反光区都不会被挖空。不依赖纯黑吸光布。

横放、竖放、倒置和一定程度的倾斜可识别。根据彩色色卡自动转正为“公司名称在上方、色卡在左侧”，并校正轻微歪斜。只旋转、不拉伸板子，保留原始透视。色卡缺失、遮挡或方向证据冲突时明确报错，不输出猜测朝向的图片。板子应完整拍入照片，边界不可严重模糊或完全融入背景。找不到完整板边时明确报错，不拿“只有饮片”的结果代替整板。

标尺默认 `erode: 0, feather: 0, pad: 30, size: 1200, max_kb: 3072`。需 800 像素时，可将生成的白底图放入 1药城压缩文件夹，得到 800×800、≤2000KB 的图。

全部回归测试：在程序文件目录运行 `python -B -m unittest discover -p "test_*cutout.py" -v`。
